## How to import
1. Open diagrams.net (draw.io).
2. Create a blank diagram.
3. Set light mode: Extras -> Theme -> Light.
4. Set white page background: File -> Page Setup -> Background -> white.
5. Open any .mmd file and copy all text.
6. In draw.io use: Arrange -> Insert -> Advanced -> Mermaid.
7. Paste the Mermaid code and click Insert.

## Export without black background
1. File -> Export as -> PNG or SVG.
2. Disable Transparent background.
3. For PNG, set Scale = 2x or 3x.
